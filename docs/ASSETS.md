# Public examples

Three original synthetic adults generated with the built-in image generation tool for this project. These are public style examples, never customer results. No reference customer photographs were used.

- Cinematic: synthetic adult man, original cinematic coat, dramatic amber light; no text, logos or celebrity likeness.
- Studio: synthetic adult woman, elegant black clothing, natural skin texture, refined studio lighting; no text or logos.
- Fantasy: synthetic adult woman, original science-fiction armor, violet lighting; no copyrighted character design or text.

Original 1024×1536 files were resized to 800×1200 and encoded as WebP for public page performance. Files: `public/portraits/cinematic.webp`, `studio.webp`, `fantasy.webp`.

Fonts: Noto Sans Arabic and Noto Sans Georgian, bundled locally in WOFF format. Original copyright/license metadata accompanies each family in `public/fonts`. SIL Open Font License 1.1.
